# 示例：增强后的提示词

以下是用 `dsh-prompt-enhancer` 增强 `Write a weekly summary report`（写一份周报总结）后生成的输出示例。

> 提示：增强结果的**语言跟随你的输入语言**（中文输入 → 中文输出，英文输入 → 英文输出）。下方展示中文输入对应的输出。

## 输入

```
帮我写一份周报总结
```

## 增强输出

```markdown
## 目标
生成一份可直接提交的周报总结，涵盖本周工作内容、成果、问题与下周计划，便于向团队或上级同步进展。

## 背景
你希望用结构清晰、重点突出的周报来总结本周工作。请用下方占位符对应的实际内容替换。

## 任务要求
- 总结本周完成的任务、里程碑与成果
- 列出遇到的阻塞或问题及其当前状态
- 按优先级列出下周计划的工作
- 语气简洁专业，使用要点式短句

## 输出格式
Markdown，包含四个小节：本周工作 / 成果 / 问题 / 下周计划

## 验收标准
- 四个小节齐全且非空
- 无残留占位符
- 可直接提交
```

## 说明

- 当模型判断关键信息缺失时（例如"本周完成了哪些工作？""周报给谁看？"），会先弹出**提问卡片**，你回答后再生成最终结果。
- 生成结果先进入**预览卡片**，确认后点「应用到输入框」才会写入输入框，**不会自动发送**。
