# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |

## Reporting a vulnerability

If you find a security issue in this plugin, please report it privately via
GitHub's security advisory feature:

https://github.com/yaoshuo530/dsh-prompt-enhancer/security/advisories/new

Please **do not** open a public issue for security vulnerabilities. You should
receive a response within a few days.
